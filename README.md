# Desenvolvimento Front-End — Estudos e Trabalho da Faculdade

Este repositório reúne exercícios de estudo e um trabalho acadêmico da disciplina de Desenvolvimento Front-End, do curso de Ciência da Computação. O objetivo é praticar a criação de páginas web com HTML5, CSS e JavaScript, sem dependências externas.

## Sobre o projeto

A Rede Acolher é uma ONG fictícia criada para o trabalho da faculdade. O site demonstra apresentação institucional, projetos sociais, campanhas de doação e cadastro de voluntários. Os dados, indicadores e contatos são ilustrativos.

## Arquivos

- `index.html`: página inicial e informações de contato.
- `projetos.html`: iniciativas sociais e formas de participação.
- `cadastro.html`: formulário demonstrativo.
- `styles.css`: estilos e layout responsivo.
- `script.js`: máscaras e validações do formulário.

## Como executar

Baixe os arquivos, mantenha todos no mesmo diretório e abra `index.html` em um navegador moderno. Não é necessário instalar pacotes ou ferramentas.

## Finalidade acadêmica

O projeto é destinado exclusivamente ao aprendizado e à avaliação acadêmica. O formulário valida os dados no navegador, sem enviá-los ou armazená-los. O site não recebe pagamentos ou doações reais.
